<p align="center"> “𝗂’𝗏𝖾 𝖻𝖾𝖾𝗇 𝗐𝗈𝗋𝗌𝖾,” 𝗃𝖺𝗌𝗈𝗇 𝖺𝗌𝗌𝗎𝗋𝖾𝖽 𝗁𝖾𝗋. “𝗈𝗇𝖼𝖾 𝗂𝗇 𝗈𝗋𝖾𝗀𝗈𝗇, 𝗍𝗁𝗂𝗌 𝖽𝗋𝖺𝖼𝖺𝖾𝗇𝖺 𝖼𝗎𝗍 𝗈𝖿𝖿 𝗆𝗒 𝖺𝗋𝗆𝗌.” </p>
